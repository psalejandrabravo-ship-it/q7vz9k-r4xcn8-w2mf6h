# El viaje de los corazones

Juego web de MIRARIM para educadoras y educadores de educación parvularia.

Facilita conversación, empatía y toma de decisiones en grupo. No diagnostica ni sustituye una intervención profesional.

## Mundos

1. **El Jardín de la Amistad** — elegir la lámina correcta  
2. **El Parque de los Sentimientos** — ¿estuvo bien? Sí / No  
3. **La Escuela del Compartir** — reconocer la emoción  
4. **El Reino de la Bondad** — ordenar los pasos (arrastrar A, B y C)

## Cómo jugar

Se proyecta en horizontal (computador o celular acostado). Los niños votan; la persona adulta marca la opción del grupo. La narración se activa solo al tocar el ícono de audio.

No se guardan nombres ni datos personales. Solo el progreso de situaciones completadas, en el navegador.

## Desarrollo

```bash
npm install
npm run dev
```

Requiere Node 22.
